# Octa.rio User Guide

A quick guide to using the flood monitoring system for Rio de Janeiro.

## Dashboard Overview

The main dashboard displays real-time flood monitoring data.

![Dashboard Overview](screenshots/dashboard.png)

**Key Metrics:**
- Total regions monitored
- Active alerts count
- Average risk level
- Active cameras

## Map Navigation

The interactive map shows all monitored regions with color-coded risk levels.

![Map View](screenshots/map.png)

**Risk Colors:**
- 🟢 Green: Low risk
- 🟡 Yellow: Moderate risk
- 🟠 Orange: High risk
- 🔴 Red: Critical risk

**Actions:**
- Click any marker to view region details
- Zoom in/out using map controls
- Pan by clicking and dragging

## Region Cards

Browse all regions in a scrollable list below the map.

![Region Cards](screenshots/regions.png)

**Features:**
- Search by region name
- Filter by risk level
- View alert count per region
- Click card to open details

## Region Details

Click any region to open detailed information.

![Region Details Modal](screenshots/region-details.png)

**Tabs:**
- **Overview**: Current status, risk level, active alerts
- **Alerts**: List of all active alerts with timestamps
- **Cameras**: Live camera feeds from the region

## Search & Filter

**Search:**
- Type region name in search box
- Results update instantly

![Search](screenshots/search.png)

**Filter:**
- Click filter dropdown
- Select risk level
- View matching regions only

![Filter](screenshots/filter.png)

## Camera Feeds

View live camera feeds from any region.

![Camera Feeds](screenshots/cameras.png)

- Switch between cameras using tabs
- Feeds update in real-time
- Camera status indicator shows connection

## Theme Toggle

Switch between light and dark modes.

![Theme Toggle](screenshots/theme.png)

- Click theme icon in header
- Preference saved automatically
- Works across all pages

## Tips

- Refresh page for latest data
- Use filters to focus on high-risk areas
- Check camera feeds for real-time conditions
- Alert counts update automatically
